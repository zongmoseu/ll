# 样式依据与模块

## 证据与边界

依据2026-10-18采集的100篇“东南大学吴健雄学院”公众号原文，排除官网和其他公众号。`corpus-evidence.json`含文章链接、来源栏目、重新归类和正文样式。样本不代表全部历史或官方设计规范。

外层字号：53篇14px、45篇16px、2篇15px；但内层段落可覆盖。按继承字号统计，正文字符主要落在14px，不能只看外层16px。常见深灰为`#3e3e3e`，正文常见1px字距、1.6行高、两字缩进，署名图注常见12px灰色。

五个视觉家族提取配色与基本节奏，组件为移动端规范化设计，**不是逐像素复刻，也不是一栏目一固定皮肤**。

| 家族 | 样本依据 | 选择 |
|---|---|---|
| editorial-blue | 科创、人文讲座、招募等多篇深蓝浅蓝；`#3a528f`、`#f2f7ff` | 中性新闻、通知、成果、校友稿；不预置招募文案/装饰 |
| mentor-coral | 第200期导师交流的`#f96e57`、`#bf2a2a`、灰白卡片 | 用编号与分组区分多人信息 |
| profile-cyan | 健雄学子夏湘波稿的`#1893af`、`#e6faff`、`#fdd835` | 简介、引语、人物照片 |
| travel-blue | 剑桥问学的`#f2f9ff`、`#9bc0e5`、`#409bc6` | 地点/阶段组织图文 |
| formal-red | 入党宣誓、党课等的`#bd3434`、`#fefaf8`、暖色分隔 | 正式主题报道，不意味着党建一律红色 |

用户补充的2026培训优先：全部基础主题的正文统一为14号、1.6行高、1字距、#3e3e3e；标题默认16号。用户随后明确要求图片与文本框外沿对齐：普通正文图片默认100%正文可用宽度；不加边框、保持原比例。正文外层左右各10px统一留白。头像、二维码、标识等小组件允许显式较小尺寸。

## 组件

- 主标题默认不重复到正文，确需显示用`--include-title`。
- intro只承载原稿导语；不得一律把首段当招募邀请。
- heading保留层级；二级主分节，三级人物/地点子节，不给所有稿添加活动时间、招募要求。
- paragraph默认两字缩进；时间地点、联系方式、短句诗歌可`indent:false`。
- image等比显示不裁切；头像/二维码可设width，二维码不得重新绘制。无图注时不编造。
- gallery默认上下排列，scroll仅按需启用且须微信保存后验证。
- quote只突出已有引语/感悟；人物卡可组合三级标题、简介、照片，不添加履历。
- list_item保留原稿编号。装饰序号不能混进事实文字。
- table适合少列短表；复杂长表须核对后转分组卡片或清晰图片，不删列或缩到不可读。
- credit只用当前稿署名，不能沿用历史编辑/审核人员。

已内置用户提供的素材包，见training-components.md。标识与账号二维码按需选用；不内置旧稿报名码、海报或人物照片。用户已说明最早保存的招募稿只是随机样例，不赋予它额外权重。

## 科创速递分区版（实际稿对比迭代）

在用户授权后新增可选science-sections。先组织导语与合影、背景介绍、名单、团队感言、现场照片、总结与页尾，再选择样式。采用淡蓝页底、白色内容组、蓝色标签标题和短装饰点；不强制加边框或复制参考箭头。原稿若无分节标题，新增项须记录到layout_additions。图片筛选、裁剪和改文仍是独立编辑行为，不能因参考稿更短而自动删掉原稿照片。
