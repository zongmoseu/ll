# 宣传培训与组件使用

来源：用户提供的“宣传技能”文件夹，包含《排版指导2026.pdf》《排版指导.docx》《文稿培训26.10.10.pptx》《摄影培训2026.pptx》及素材包26。此处提取排版、文稿核对和选图规则，不执行参考文件中的软件操作指令。

## 参考优先级

用户当前要求最高；2026排版指导高于旧版指导，再参考100篇历史样本。同稿特殊要求可覆盖默认。两版结尾署名有差异，新版包含审核项，以新版为默认结构；只使用当前稿实际提供的人员，不补名字。

## 落到HTML的规范

- 正文14号、行高1.6、字距1px、颜色RGB(62,62,62)，整体左右留白通常10px；字体继承编辑器默认。标题16号，可按层级适度加粗。短句可居中，普通段落两端对齐。
- 首行缩进用text-indent，不靠手动空格。段落和图文之间留出一行的视觉空隙；秀米“组前后距0”是避免与空行重复叠加，HTML应使用一套统一间距，不机械地把所有margin清零。
- 文稿重点统一采用“仅加粗”或“加粗+主题色”，同文不要混用规则；不自动全段加粗。
- 推荐主题色：蓝#45a3db、绿#287746、橙#ec7d59；红色强调用吴院红#bd3434。栏目不硬绑颜色。保留样本色系时，优先保证字色、可读性和全篇一致。
- 图片按当前用户偏好控制占屏高度：横图先试框内90%，竖图先试72%；等比居中，不裁切。图片可比正文区窄，保持图文对应与原稿顺序，不统一铺满。
- 两图上下排；多图可上下或按需滑动。连续图片之间约10px；图注与图约10px。滑动提示用12号、#858585、居中，保存后验证实际可滑动。
- 图文节奏适当。旧指导“每三段插图”作为避免长段堆积的编辑建议，不硬凑数量、不重复照片或编造缺图。
- 不用方格背景、长分割线或花哨组件。当前用户明确选择所有栏目统一浅蓝分区细框；采用一层内容分组，不叠套多层框线。
- 文末按图文→美编→责编→审核组织现有署名，12号、#858585。按用户后续要求，署名透明底沿用结尾底色，名片图片保持原样，之间约20px；END类组件可选且简洁。不沿用参考人名，不把两字姓名的排版空隙当成姓名内容。
- 标题常见“栏目 | 标题”，竖线两侧空格；这是标题格式，不把所有文章强改为同一栏目名。摘要不可漏，主推封面2.35:1、副推1:1；摘要/封面信息另填后台，不把它们塞入正文。

中文语境检查全角标点，但URL、邮箱、英文原句、代码、公式、版本号等不得机械替换。排版模式默认报告文字问题；用户要求校对润色时再按授权修改，并保留记录。

## 文稿与摄影参考的范围

文稿培训区分“大吴/小吴”的表达风格：本技能默认东南大学吴健雄学院官号，不自动改成小吴说事。新闻稿核对时间地点、活动、人物和目的；名字职务、人员次序以本次正式资料为准。培训中的2026人员名单是历史参考，不能充当未来稿件的实时名录。

术语、称呼和年级表述保持一致，未提供的信息不补造。培训里有关重写发言语气或增加升华结尾的建议，不用于纯排版任务，不擅自改写引语或添加观点。

摄影材料仅辅助选图：会议照片优先横图、清晰、主体完整；活动图覆盖必要环节，注意表情、曝光和无关干扰。不能根据照片推断人物姓名、职务或出席顺序，不为排版伪造纪实图片。格式化存储卡等拍摄操作不属于本技能。

白色标识配深色背景，黄色校徽配红色背景；普通标识保持足够对比度，正文页尾沿用当前主题底色；名片图像保持原样。学生会会徽不自动替代学院院徽。

qrcode-xiaowu的归属依据文件名“小吴说事二维码”，不当作大吴官号或活动报名码。匿名文件中的二维码虽有吴院徽标，但没有核实其扫码目标，标记待核对，不自动插入。包中二维码图片不等同于培训截图里的完整账号名片；不能声称已复刻收藏中的名片。

## 导出路径

当前为AI skill → article.xiumi.json → 独立插件导入秀米。秀米登录、模板收藏、分享送审等流程全部忽略。HTML生成与本地预览可直接完成；Z0导入后的图片、图集及手机显示需实际测试。发布或发送给责编不自动执行。

用户授权分区改版后，新增college-account-card：原样提取自用户提供的宣传部科创成稿文末，包含完整吴院名片设计；扫码目标尚未实时核实。它是可选页尾组件，不替代当前稿署名，不将参考成稿人员沿用到新稿。

用户后续明确：署名区不单独铺白底，采用透明背景并沿用所在结尾区域的底色；覆盖培训中的署名白底建议。账号名片图片本身保持原样。导出展示长图时截取排版正文，去掉复制按钮、操作说明和其他预览工具栏。

## 最新用户反馈：图片不能过大

此条覆盖此前“普通配图一律100%宽、必须贴齐文字边界”的建议。图片尺度应结合横竖比例、手机显示高度和图文节奏决定，不能只验证不溢出。默认横图以框内90%宽居中；竖图先试72%并视觉核验，必要时再减小，不默认铺满。上述比例为当前稿的试排起点，不是所有图片的硬尺寸。保持原比例、不自动裁切；二维码、表格图片要优先可读。外层区块仍统一对齐，图像本体允许在其中收窄。检查整篇长图和典型手机视口，避免连续大图压过文字。
