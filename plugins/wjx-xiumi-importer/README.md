# 吴院推送导入助手

独立Chrome／Edge扩展，与 `skills/wjx-wechat-layout` 配合。**不需要本地工作台、Node.js服务或AI API Key。** AI侧完成排版，插件只处理导入和核验。

1. 在扩展管理页开启开发者模式，加载本文件夹（直接包含manifest.json）。
2. 把Word与可选图片包交给AI，使用吴院排版skill，取得`article.xiumi.json`。
3. 登录秀米、新建空白图文，打开本插件并选择该文件。
4. 点击“导入正文与图片”，等待图片上传和正文写入。不要在导入过程中切换稿件。
5. 核对标题和摘要，在秀米手动保存。重新打开文章后，使用“保存并重开后，核验稿件”。

该数据包包含图片文件内容，无须逐张选择本地照片；账号权限和图片上传仍受秀米实际服务约束。插件不会自动发布。当前已通过模拟编辑器测试，真实账号导入与保存仍需验证。

数据仅存于浏览器扩展本地存储；无工作台连接、遥测或后台自动运行。上游导入核心及许可证见NOTICE.md与UPSTREAM-LICENSE。
